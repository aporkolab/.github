## How the defaults work

This public `.github` repository supplies GitHub's supported community files when a repository has no corresponding local file. Local guidance takes precedence. A repository with its own issue templates or issue-template configuration uses those instead of this set.

These files are defaults, not files copied into every project. The documents under `docs/` are reference material; they do not automatically configure agents, checks, or repository permissions.

See [GitHub's documentation on default community files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
