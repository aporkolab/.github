# Getting help

Start with the project's README and any repository-specific documentation. Search its open and closed issues for the error or behavior you are seeing.

For a question, use the repository's Discussions tab if it is enabled. Otherwise, open an issue in the affected repository and describe what you are trying to do, what you have tried, and where you got stuck.

For a reproducible bug or a feature request, use the relevant issue form. Include the version and environment when they matter. Keep unrelated problems in separate issues.

Do not put passwords, tokens, or private data in public reports. For a suspected vulnerability, follow the repository's security policy or use **Security → Report a vulnerability** where available.
